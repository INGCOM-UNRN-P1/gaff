# 0x000Ah: Escribí comentarios que expliquen el "porqué", no el "qué"

```{admonition} Categoría: Sintaxis Básica y Nomenclatura (0x00XX)
:class: note
Código de regla: `0x000Ah` | Soporta autofix automático: **No**
```

## Fundamentación y Justificación Pedagógica

Los comentarios deben aportar valor y aclarar la intención detrás del código, no parafrasear lo que el código ya expresa de forma evidente. El código en sí mismo debe ser lo suficientemente claro para explicar *qué* hace.

El cumplimiento de esta pauta asegura la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
// Incrementa i en 1
i++;
```

### Código Conforme (Recomendado)

```{code-block} c
// Usamos índice inverso porque el último byte define la paridad del paquete
for (size_t i = len - 1; i < len; i--)
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
