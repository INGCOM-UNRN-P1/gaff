# 0x0017h: Espaciado consistente en declaraciones de doble puntero (tipo **var)

```{admonition} Categoría: Sintaxis Básica y Nomenclatura (0x00XX)
:class: note
Código de regla: `0x0017h` | Soporta autofix automático: **Sí**
```

## Fundamentación y Justificación Pedagógica

En declaraciones de tipos puntero a puntero, los asteriscos deben ir unidos entre sí y junto al identificador ('char **argv'), evitando 'char* *argv', 'char * * argv' o 'char** argv'.

El cumplimiento de esta pauta asegura la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
int main(int argc, char** argv)
```

### Código Conforme (Recomendado)

```{code-block} c
int main(int argc, char **argv)
```
