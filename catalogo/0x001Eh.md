# 0x001Eh: Prohibición de múltiples espacios en blanco consecutivos dentro de una línea de código

```{admonition} Categoría: Sintaxis Básica y Nomenclatura (0x00XX)
:class: note
Código de regla: `0x001Eh` | Soporta autofix automático: **Sí**
```

## Fundamentación y Justificación Pedagógica

Salvo la sangría inicial que delimita los bloques, no deben colocarse dos o más espacios consecutivos entre identificadores, operadores o palabras clave.

El cumplimiento de esta pauta asegura la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
int   total   =   cantidad  *  precio;
```

### Código Conforme (Recomendado)

```{code-block} c
int total = cantidad * precio;
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
