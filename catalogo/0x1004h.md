# 0x1004h: Las condiciones complejas deben ser simplificadas o comentadas Si una

```{admonition} Categoría: Estructuras de Control y Lazos (0x10XX)
:class: note
Código de regla: `0x1004h` | Soporta autofix automático: **No**
```

## Fundamentación y Justificación Pedagógica

condición contiene múltiples operadores lógicos,     considerá dividirla en partes más pequeñas usando variables lógicas             auxiliares explicativas o funciones de validación.-         **Incorrecto(difícil de leer)     : ** ```` c if ((usuario_activo && tiene_permisos) ||             (es_admin && !modo_mantenimiento)) {     // ... } ```` <!-- c -->

El cumplimiento de esta pauta asegura la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
if ((usuario_activo && tiene_permisos && !mantenimiento) || (es_admin && clave_maestra))
```

### Código Conforme (Recomendado)

```{code-block} c
bool es_valido = usuario_activo && tiene_permisos;
if (es_valido) { ... }
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
