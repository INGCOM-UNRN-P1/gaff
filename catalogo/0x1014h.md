# 0x1014h: Prohibición de expresiones de asignación dentro de estructuras de control

```{admonition} Categoría: Estructuras de Control y Lazos (0x10XX)
:class: note
Código de regla: `0x1014h` | Soporta autofix automático: **No**
```

## Fundamentación y Justificación Pedagógica

La asignación embebida dentro de condiciones de control ('if ((x = f()) != 0)', 'while ((c = getchar()) != EOF)') dificulta la legibilidad, fomenta la confusión entre '=' y '==' y quiebra el principio pedagógico de una acción por sentencia.

El cumplimiento de esta pauta asegura la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
while ((c = getchar()) != EOF)
if ((res = procesar()) == 0)
```

### Código Conforme (Recomendado)

```{code-block} c
int c = getchar();
while (c != EOF) {
    // ...
    c = getchar();
}
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
