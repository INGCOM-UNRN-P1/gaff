# 0x2012h: Prohibición de asignaciones múltiples a una variable sin lectura intermedia (dead store)

```{admonition} Categoría: Funciones y Modularización (0x20XX)
:class: note
Código de regla: `0x2012h` | Soporta autofix automático: **No**
```

## Fundamentación y Justificación Pedagógica

Asignar consecutivamente valores a una variable sin realizar lecturas intermedias descarta el valor previo sin efecto útil, indicando errores de lógica, código residual o asignaciones redundantes.

El cumplimiento de esta pauta asegura la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
int valor = 10;
valor = 20; // Dead store: el 10 nunca fue leído
```

### Código Conforme (Recomendado)

```{code-block} c
int valor = 10;
printf("%d\n", valor);
valor = 20;
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
