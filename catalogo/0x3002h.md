# 0x3002h: Liberá siempre la memoria dinámica y asigná NULL al puntero para evitar punteros colgantes

```{admonition} Categoría: Punteros y Gestión de Memoria (0x30XX)
:class: note
Código de regla: `0x3002h` | Soporta autofix automático: **No**
```

## Fundamentación y Justificación Pedagógica

Por cada asignación de memoria dinámica debe existir una correspondiente liberación con `free()`. Inmediatamente después de liberar la memoria, asigná `NULL` al puntero para prevenir fallos por acceso a punteros colgantes (*dangling pointers*).

El cumplimiento de esta pauta asegura la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
free(ptr);
// ptr sigue apuntando a memoria liberada
```

### Código Conforme (Recomendado)

```{code-block} c
free(ptr);
ptr = NULL;
```
