# 0x300Fh: Liberá la memoria en el orden inverso a su asignación

```{admonition} Categoría: Punteros y Gestión de Memoria (0x30XX)
:class: note
Código de regla: `0x300Fh` | Soporta autofix automático: **No**
```

## Fundamentación y Justificación Pedagógica

Esto es crítico en estructuras de datos anidadas, como matrices dinámicas 2D o listas enlazadas, para evitar dejar memoria inaccesible en el heap.

El cumplimiento de esta pauta asegura la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
free(nodo);
// nodo->nombre quedó huérfano (leak)
```

### Código Conforme (Recomendado)

```{code-block} c
free(nodo->nombre);
free(nodo);
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
