# 0x4002h: Validá los retornos de las operaciones de lectura y escritura de archivos

```{admonition} Categoría: Gestión de Archivos y Errores (0x40XX)
:class: note
Código de regla: `0x4002h` | Soporta autofix automático: **No**
```

## Fundamentación y Justificación Pedagógica

Funciones como `fread`, `fwrite`, `fgetc`, `fgets`, `fprintf` y `fscanf` devuelven valores de control. Es obligatorio verificar dichos retornos para asegurar transferencias completas e identificar fallos o el fin de archivo (EOF).

El cumplimiento de esta pauta asegura la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
fread(buf, 1, 100, f); // Sin verificar si leyó
```

### Código Conforme (Recomendado)

```{code-block} c
size_t leidos = fread(buf, 1, 100, f);
if (leidos < 100) { ... }
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
