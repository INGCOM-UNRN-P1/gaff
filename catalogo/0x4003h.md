# 0x4003h: Utilizá errno, perror y strerror para reportar fallos del sistema operativo de manera precisa

```{admonition} Categoría: Gestión de Archivos y Errores (0x40XX)
:class: note
Código de regla: `0x4003h` | Soporta autofix automático: **No**
```

## Fundamentación y Justificación Pedagógica

Cualquier fallo en llamadas de sistema de archivos (como fallos en `fopen`, `fread` o `fwrite`) establece un código de error global en la variable `errno` de `<errno.h>`. Debés usar `perror` o `strerror` de `<string.h>` para imprimir o formatear mensajes legibles de diagnóstico.

El cumplimiento de esta pauta asegura la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
if (f == NULL) { printf("Error\n"); }
```

### Código Conforme (Recomendado)

```{code-block} c
if (f == NULL) { perror("Error al abrir archivo"); }
```
