# 0x4005h: Evitá el uso de offsets y posiciones fijas codificadas a mano en archivos binarios sin validar sus dimensiones

```{admonition} Categoría: Gestión de Archivos y Errores (0x40XX)
:class: note
Código de regla: `0x4005h` | Soporta autofix automático: **No**
```

## Fundamentación y Justificación Pedagógica

Cuando leés o escribís en una posición específica de un archivo binario mediante `fseek`, debés validar que la posición de destino sea válida y no exceda las dimensiones físicas del archivo. Calculá el tamaño del archivo usando `fseek` y `ftell` antes de realizar saltos aleatorios.

El cumplimiento de esta pauta asegura la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
fseek(f, 1000, SEEK_SET);
```

### Código Conforme (Recomendado)

```{code-block} c
if (offset < tamano_archivo) { fseek(f, offset, SEEK_SET); }
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
