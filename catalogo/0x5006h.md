# 0x5006h: Preferí fgets sobre gets y scanf para leer cadenas

```{admonition} Categoría: Compilación y Buenas Prácticas de Ingeniería (0x50XX)
:class: note
Código de regla: `0x5006h` | Soporta autofix automático: **No**
```

## Fundamentación y Justificación Pedagógica

`fgets` previene el desbordamiento de búfer de entrada de forma automática mediante la validación de tamaño del buffer de entrada.

El cumplimiento de esta pauta asegura la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
gets(buffer);
scanf("%s", buffer);
```

### Código Conforme (Recomendado)

```{code-block} c
fgets(buffer, sizeof(buffer), stdin);
```

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
