# 0x500Bh: Inclusión obligatoria de cabeceras estándar para funciones de la biblioteca C

```{admonition} Categoría: Compilación y Buenas Prácticas de Ingeniería (0x50XX)
:class: note
Código de regla: `0x500Bh` | Soporta autofix automático: **No**
```

## Fundamentación y Justificación Pedagógica

Toda invocación a funciones estándar de C requiere la inclusión explícita de su respectiva cabecera: printf/scanf (<stdio.h>), malloc/free/exit (<stdlib.h>), strcmp/strlen (<string.h>), assert (<assert.h>).

El cumplimiento de esta pauta asegura la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
int main(void) {
    printf("hola");
    return 0;
}
```

### Código Conforme (Recomendado)

```{code-block} c
#include <stdio.h>
int main(void) {
    printf("hola");
    return 0;
}
```
